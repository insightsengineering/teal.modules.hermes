# Validation of Number of Levels

This validation function checks that a given vector `x` is a factor with
the specified number of levels.

## Usage

``` r
validate_n_levels(x, name, n_levels)
```

## Arguments

- x:

  (`factor`)  
  factor to validate.

- name:

  (`string`)  
  name of `x` in the app.

- n_levels:

  (`count`)  
  required number of factor levels in `x`.
