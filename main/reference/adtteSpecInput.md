# Module Input for `ADTTE` Specification

This defines the input for the `ADTTE` specification.

## Usage

``` r
adtteSpecInput(inputId, label_paramcd = "Select Endpoint")
```

## Arguments

- inputId:

  (`string`)  
  the ID used to call the module input.

- label_paramcd:

  (`string`)  
  label for the endpoint (`PARAMCD`) selection.

## Value

The UI part.

## See also

[`adtteSpecServer()`](https://insightsengineering.github.io/teal.modules.hermes/reference/adtteSpecServer.md)
for the module server and a complete example.
