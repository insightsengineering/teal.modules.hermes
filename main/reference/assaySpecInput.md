# Module Input for Assay Specification

This defines the input for the assay specification.

## Usage

``` r
assaySpecInput(inputId, label_assays = "Select Assay")
```

## Arguments

- inputId:

  (`string`)  
  the ID used to call the module input.

- label_assays:

  (`string`)  
  label for the assay selection.

## Value

The UI part.

[`assaySpecServer()`](https://insightsengineering.github.io/teal.modules.hermes/reference/assaySpecServer.md)
